# Image PDF Reader (OCR)

Небольшой CLI-скрипт для распознавания текста (OCR) в PDF/изображениях и сохранения результатов в отдельную папку проекта.

Что делает:
- Принимает путь к входному файлу (PDF или изображение) через терминал.
- Создаёт папку `output` в корне проекта (по умолчанию) и сохраняет туда:
  - поисковый PDF c текстовым слоем: `<имя>__ocr.pdf`
  - извлечённый текст (sidecar): `<имя>__ocr.txt`
- Избегает перезаписи: при совпадении имён добавляет суффиксы `-1`, `-2`, ... (если не указать `--overwrite`).

## Требования
- Python 3.9+
- Tesseract OCR (с языковыми данными для нужных языков, напр. `rus`)
- Ghostscript

Python-зависимость:
- `ocrmypdf` (см. `requirements.txt`)

## Установка (Windows, cmd.exe)
1) (Опционально) создать и активировать виртуальное окружение:
```bat
python -m venv .venv
".venv\Scripts\activate"
```

2) Установить Python-зависимости:
```bat
pip install -r requirements.txt
```

3) Установить системные зависимости (один из вариантов):
- Через Winget:
```bat
winget install --id=UB-Mannheim.TesseractOCR -e
winget install --id=ArtifexSoftware.Ghostscript -e
```
- Либо скачайте инсталляторы Tesseract и Ghostscript с официальных сайтов и установите, убедившись, что они в PATH.

Проверьте, что команды доступны:
```bat
tesseract --version
gswin64c --version
```

## Использование
Запуск из корня проекта (cmd.exe):
```bat
python main.py "C:\путь\к\файлу.pdf"
```
- По умолчанию результаты будут в: `C:\Users\...\Image_PDF_Reader\output`.

Опции:
- Задать другую папку вывода:
```bat
python main.py "C:\путь\к\файлу.pdf" -o "C:\путь\к\папке_результатов"
```
- Указать языки Tesseract (например, русский+английский):
```bat
python main.py "C:\путь\к\файлу.pdf" -l rus+eng
```
- Отключить прогресс-бар:
```bat
python main.py "C:\путь\к\файлу.pdf" --no-progress
```
- Разрешить перезапись существующих файлов:
```bat
python main.py "C:\путь\к\файлу.pdf" --overwrite
```

### Очистка страниц (шумы) — флаг `--clean`
- Очистка (clean) использует внешнюю утилиту `unpaper`, которая чаще всего недоступна на Windows.
- По умолчанию очистка выключена (ошибок с `unpaper` не будет).
- Если хотите попробовать очистку, добавьте флаг:
```bat
python main.py "C:\путь\к\файлу.pdf" --clean
```
  - Если `unpaper` не найден, скрипт автоматически продолжит без очистки и выведет предупреждение.

Справка:
```bat
python main.py --help
```

## Подсказки и типичные проблемы
- Ошибка про отсутствующий `ocrmypdf`: установите зависимости `pip install -r requirements.txt`.
- Ошибка про Tesseract/Ghostscript: установите их и добавьте в PATH (перезапустите терминал после установки).
- Русский язык: убедитесь, что при установке Tesseract выбран пакет `rus` (или установите языковые данные отдельно).
- Утилита `unpaper` обычно отсутствует на Windows. Поэтому `--clean` опционален; без него OCR работает нормально.
